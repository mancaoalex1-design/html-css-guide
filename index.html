📄 Module 1: HTML Document Skeleton & Metadata

HTML Structure
<!DOCTYPE html>, <html>, <head>, <body> Root Document Boilerplate
This is For Establishing the mandatory structural skeleton required for every valid modern web page.
What Will Happen The browser operates in HTML5 Standards Mode. It parses document metadata in <head> and displays rendered elements inside <body>.
👁️ Live Conceptual Representation
<html lang="en">
├── <head> (Metadata, charset, title, styles - invisible to user)
└── <body> (Visible screen canvas containing all tags below)
<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Page Title</title>
  </head>
  <body>
    <!-- All your visible website content goes here -->
  </body>
</html>

🔗 Module 4: Hyperlinks & Navigation Anchors

Links

This is For Navigating to another URL, jumping to a section ID on the current page, triggering phone calls, emails, or downloading files.
What Will Happen Turns text into a clickable link. Clicking opens the target page in a new tab (target="_blank"), triggers an email client (mailto:), or jumps immediately down the page.
👁️ Live Rendered Result

  Visit Example
</a>

🎯 Module 11: CSS Selectors & Specificity

CSS Core
Element, .class, #id, :hover, :nth-child(), ::before Targeting Elements
This is For Targeting specific elements on the page to apply styles based on tag name, class, ID, user interactions (hover, focus), or position.
What Will Happen Only the matching elements receive the styles. Pseudo-classes like :hover react dynamically in real-time when the user points their mouse.
👁️ Live Interactive Hover Demo
💡 Rule of thumb: Prefer .classes over #ids for reusable styles. 
/* Element Selector */
p { color: #f8fafc; }

/* Class Selector (Best practice for reuse) */
.btn-primary { background: #38bdf8; }

/* ID Selector (High specificity) */
#main-header { position: sticky; }

/* Pseudo-Class: Triggers on mouse hover */
button:hover { transform: translateY(-2px); }

/* Pseudo-Class: Triggers when clicked/focused */
input:focus { border-color: #a855f7; }

/* Pseudo-Class: Alternating row colors */
tr:nth-child(even) { background: #1e293b; }

/* Pseudo-Element: Inserts decorative content */
.quote::before { content: "“"; font-size: 2rem; }

📦 Module 12: CSS Box Model & Sizing

Box Model
margin, border, padding, content & box-sizing The Core Layout Formula
This is For Controlling the exact space around elements, inside element borders, and how total width is calculated.
What Will Happen Padding pushes content inwards from the border; Margin pushes neighboring elements away; box-sizing: border-box stops padding from inflating the box width.
👁️ Visual Box Model Diagram
MARGIN (Outer spacing between neighbors)
BORDER (The perimeter edge)
PADDING (Inner breathing room)
CONTENT (Text / Images / Children) 
/* Universal reset: keeps padding INSIDE width/height */
* {
  box-sizing: border-box;
}

.box {
  width: 300px;
  /* Top Right Bottom Left (Clockwise) */
  margin: 20px auto;    /* Pushes external siblings away */
  border: 2px solid #38bdf8; /* Visible perimeter frame */
  padding: 16px 24px;   /* Room between content and border */
}

📱 Module 18: Responsive Design & Media Queries

Responsive
@media (max-width: 768px) { ... } Responsive Conditional Styles
This is For Applying specific CSS rules only when the screen size matches a condition (like smartphones or tablets).
What Will Happen Multi-column desktop layouts automatically collapse into comfortable single-column mobile views on smaller screens.
👁️ Responsive Strategy Rule

Mobile First Mindset:

1. Write base styles for mobile screens.

2. Use @media (min-width: 768px) to enhance for Tablets.

3. Use @media (min-width: 1024px) for Desktops.

/* Default base layout (Mobile: Single Column) */
.content-grid {
  display: grid;
  grid-template-columns: 1fr;
}

/* Tablet & Desktop Enhancement */
@media (min-width: 768px) {
  .content-grid {
    grid-template-columns: repeat(2, 1fr);
  }
}

/* Large Desktop */
@media (min-width: 1024px) {
  .content-grid {
    grid-template-columns: repeat(3, 1fr);
  }
}
