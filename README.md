# HTML & CSS Interactive Learning Guide

An all-in-one interactive reference and cheatsheet built to help you master and relearn HTML & CSS syntax.

## 📁 File Location
- **Interactive File:** [`index.html`](file:///C:/Users/manca/.gemini/antigravity-ide/scratch/html-css-learning-guide/index.html)

---

## 🌟 What's Included

### 1. In The Display
- **🎯 "This is For" Badge:** Clearly states what every tag and property is used for in plain English.
- **⚡ "What Will Happen" Badge:** Explains what visual or behavioral effect occurs when implemented in a browser.
- **👁️ Live Rendered Result:** Real visual previews, including interactive accordions, native modal dialogs, and a live flexbox alignment sandbox.
- **💻 Exact Code Snippet:** Clean code examples with a 1-click **📋 Copy** button.
- **🔍 Real-Time Search Filter:** Type any tag or property (`flex`, `grid`, `form`, `table`, `modal`, `button`) in the search bar to jump right to it.

---

### 2. In The Code (Rich Comments)
Every single module and syntax block contains structured comments:
```html
<!-- ==============================================================
     SYNTAX: <tag> ... </tag>
     THIS IS FOR:
       [Plain explanation of purpose]
     WHAT WILL HAPPEN AFTER IMPLEMENTING:
       [Visual & functional behavior explanation]
     ============================================================== -->
```
And in CSS:
```css
/* ==============================================================
   SYNTAX: display: flex;
   THIS IS FOR:
     [Plain explanation of purpose]
   WHAT WILL HAPPEN AFTER IMPLEMENTING:
     [Visual & functional behavior explanation]
   ============================================================== */
```
